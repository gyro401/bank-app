# Console Bank App

Простое консольное банковское приложение, разработанное на Java с использованием Spring Framework. Проект эмулирует базовую работу банковской системы с пользователями и счетами в памяти (In-Memory).

## 🛠 Технологии
* **Java** 
* **Spring Framework** (Core, Context)
* **Инструменты сборки:** Maven / Gradle

## ⚙️ Архитектура и паттерны
* **Dependency Injection (DI):** Внедрение зависимостей через конструкторы (IoC-контейнер Spring).
* **Паттерн Стратегия (Strategy):** Обработка консольных команд реализована через интерфейс `Operation`. Приложение автоматически собирает все доступные команды (`List<Operation>`) в Map, что позволяет легко добавлять новые операции, не меняя основной цикл слушателя `OperationsConsoleListener`.
* **In-Memory хранилище:** Данные хранятся в `ConcurrentHashMap` с использованием `AtomicLong` для генерации уникальных ID.

##  Функционал (Доступные команды)
При запуске приложение слушает консоль и принимает следующие команды:

* `USER_CREATE` — создание нового пользователя.
* `SHOW_ALL_USERS` — вывод списка всех зарегистрированных пользователей и их счетов.
* `ACCOUNT_CREATE` — открытие нового счета для существующего пользователя.
* `ACCOUNT_DEPOSIT` — внесение средств на счет.
* `ACCOUNT_WITHDRAW` — снятие средств со счета.
* `ACCOUNT_TRANSFER` — перевод средств между счетами (с учетом комиссии банка).
* `ACCOUNT_CLOSE` — закрытие счета (невозможно, если это единственный счет пользователя).
