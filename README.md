# Console Bank App

Простое консольное банковское приложение, разработанное на Java с использованием Spring Framework. Проект эмулирует базовую работу банковской системы с пользователями и счетами в памяти (In-Memory).

## Технологии
* **Java 17+**
* **Spring Framework** (Context, Core)
* **Apache Maven** (сборка и управление зависимостями)

## ⚙️ Архитектура и паттерны
* **Dependency Injection (IoC):** внедрение зависимостей через конструкторы силами Spring-контекста.
* **Паттерн Стратегия (Strategy):** обработка команд консоли реализована через интерфейс `Operation`. Приложение автоматически собирает все бины операций (`List<Operation>`) в коллекцию Map, что позволяет расширять список команд без модификации слушателя `OperationsConsoleListener`.
* **In-Memory хранилище:** данные хранятся в `ConcurrentHashMap` с генерацией идентификаторов через `AtomicLong`.

## Функционал (Команды консоли)
После запуска приложение ожидает ввод одной из следующих команд:

* `USER_CREATE` — создание нового пользователя.
* `SHOW_ALL_USERS` — вывод списка всех зарегистрированных пользователей и их счетов.
* `ACCOUNT_CREATE` — открытие счета для существующего пользователя.
* `ACCOUNT_DEPOSIT` — пополнение баланса счета.
* `ACCOUNT_WITHDRAW` — снятие средств со счета.
* `ACCOUNT_TRANSFER` — перевод средств между счетами (с расчетом межбанковской/клиентской комиссии).
* `ACCOUNT_CLOSE` — закрытие счета (запрещено закрывать единственный счет пользователя).
